## Project Summary

**crypto-bot** is a paper-trading cryptocurrency bot (spot only, zero real-funds risk)
with a local rule-based + LLM-assisted strategy engine, a composite signal-scoring
system, a backtest engine, and a React "Signal Terminal" dashboard served by a Python
FastAPI backend. Market data comes from **Binance public endpoints** (no API keys
required for read path).

- **Repository type:** multi-part (Python backend + React frontend)
- **Backend:** `core/` — Python 3.11, FastAPI, stdlib-first
- **Frontend:** `dashboard/` — React 18 + Vite + TypeScript
- **Status:** active, tests passing (111 unit/integration tests)

## Key Constraints (carry into all work)

- **No real orders.** `wallet.py` is paper-only; `execution.py` never touches a live exchange.
- **Stdlib-first.** Core logic avoids heavy deps; LLM client uses `urllib`.
- **Public data only.** Binance read path needs no API keys.
- **LLM gated.** `ENABLE_LLM=1` + `LLM_API_KEY` required; otherwise strategy falls back to HOLD.
- **Scoring gate.** Trades execute only when `confidence >= 0.4` and `risk >= 0.5`.
