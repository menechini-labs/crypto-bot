# Source Tree Analysis — crypto-bot

Annotated tree (critical directories only; `node_modules/`, `.venv/`, `dist/`, `__pycache__/` omitted).

```
crypto-bot/
├── core/                      # BACKEND PART (Python engine + API)
│   ├── strategy_api.py        # FastAPI app; serves /api/* + dashboard/dist static
│   ├── strategy.py            # Base strategy interface (deterministic)
│   ├── strategy_registry/     # Strategy implementations
│   │   ├── base.py            # Strategy base class
│   │   ├── grid_strategy.py   # Grid strategy
│   │   ├── dynamic_grid_strategy.py
│   │   ├── llm_strategy.py    # LLM strategy (ENABLE_LLM gate, urllib client)
│   │   ├── registry.py        # Strategy registry/lookup
│   │   └── prompts/           # LLM prompt templates
│   ├── market.py              # Binance public REST data (no auth)
│   ├── market_ws.py           # Binance public WebSocket
│   ├── indicators.py          # RSI/volatility (stdlib)
│   ├── scoring.py             # SignalScore, score_signal, regime weights
│   ├── risk.py                # SL/TP, position guards
│   ├── backtest.py            # Backtest engine (no look-ahead, walk-forward)
│   ├── reflection.py          # ReflectionAgent (analyze closed trades)
│   ├── regime.py              # Market regime detection
│   ├── metrics.py             # Perf metrics
│   ├── reporter.py            # Equity/PnL reporter (JSON)
│   ├── wallet.py              # Paper wallet (USDT, never real)
│   ├── execution.py           # Order executor (paper)
│   ├── agent_analyzer.py      # Analyze backtest results
│   ├── synth.py               # Synthetic price series (no network)
│   ├── config_loader.py       # Loads config.yaml
│   └── dashboard.py           # (dashboard glue / legacy)
├── dashboard/                 # FRONTEND PART (React Signal Terminal)
│   ├── src/
│   │   ├── main.tsx           # Entry point
│   │   ├── Dashboard.tsx      # App shell + tabs
│   │   ├── ScorePanel.tsx     # Signal Terminal score UI + LLM button
│   │   ├── StatCard.tsx       # KPI card component
│   │   ├── EquityChart.tsx    # Equity curve chart
│   │   ├── browse/            # Strategy browse views
│   │   ├── __tests__/         # Vitest specs
│   │   ├── types.ts           # Shared TS types
│   │   └── index.css          # Signal Terminal design tokens
│   ├── index.html             # Vite entry (Syne font)
│   ├── package.json
│   └── vite.config.ts

├── run_api.py                 # Launch uvicorn backend

├── pyproject.toml             # Python project / deps
├── requirements.txt           # Pinned Python deps
├── Dockerfile                 # Backend container
├── docker-compose.yml         # Full stack (api + dashboard build)
├── tests/                     # pytest unit/integration
├── docs/                      # AI context documentation (this set)
├── _bmad/                     # BMAD Method config + manifests
├── _bmad-output/              # BMAD planning/implementation artifacts
└── data/                      # Local data cache
```

## Critical Folders

- `core/` — all engine + API logic; the single source of truth.
- `core/strategy_registry/` — pluggable strategies; add new ones here + register.
- `dashboard/src/` — frontend; consumes backend via HTTP.
- `docs/` — AI context docs (generated by BMAD Document Project).
